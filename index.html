Gestor de Precios y Stock

Inventario para almacenes y minimarkets, con un asistente que analiza los datos reales.

  • React
  • TypeScript
  • Vite
  • Tailwind
  • IndexedDB
  • PWA
  • Capacitor

Ver demo de Gestor de Precios y Stock Código de Gestor de Precios y Stock

Problema
Los almacenes de barrio llevan precios y stock en cuaderno o planilla, y se enteran de que algo se agotó cuando el cliente lo pide.
Resultado
Publicado como PWA y empaquetado para Android con Capacitor, con build automatizado en GitHub Actions.
Cómo lo hice enfoque e implementación
Enfoque
Un MVP estable antes que muchas funciones. Funciona sin backend ni conexión, con la arquitectura lista para sumar Supabase y sincronización más adelante.
Implementación
Dashboard, alertas de stock, historial, proveedores, importación/exportación CSV y respaldo JSON. "Stock Copilot" analiza el inventario en local; las acciones masivas siempre muestran vista previa y piden confirmación. Modo demo aislado en su propio espacio de almacenamiento para que nunca toque datos reales. La API key de IA vive solo en una función serverless.

OA Manager

Gestor de Objetivos de Aprendizaje. Aplicación full-stack desplegada de punta a punta.

  • React
  • Vite
  • Tailwind
  • Express
  • Prisma
  • PostgreSQL
  • Netlify
  • Render

Código de OA Manager

Problema
Hacer seguimiento de los Objetivos de Aprendizaje del currículum sin depender de planillas sueltas.
Resultado
En producción: frontend en Netlify con proxy /api/* hacia el backend en Render y la base en PostgreSQL.
Cómo lo hice enfoque e implementación
Enfoque
Separar frontend y backend, y servir la API detrás de un proxy en el mismo dominio para usar cookies de sesión first-party, sin pelear con CORS ni con cookies de terceros.
Implementación
API REST con Express y Prisma sobre PostgreSQL. Autenticación con recuperación de contraseña por enlace (correo vía Resend). Para el primer uso: modo demo con datos ficticios, tutorial inicial y ayuda contextual.

Registro Geriátrico

Registro diario de pacientes para un hogar de adultos mayores, pensado para alguien que no es técnico.

  • React
  • TypeScript
  • Vite
  • Tailwind
  • Excel
  • PWA

Código de Registro Geriátrico

Problema
Los controles diarios (signos vitales, glucemia, alimentación, sueño y más) se anotaban en papel y no había forma simple de revisarlos ni compartirlos.
Resultado
Aplicación PWA instalable que funciona offline.
Cómo lo hice enfoque e implementación
Enfoque
La usuaria principal no es técnica, así que el diseño manda: botones grandes, texto legible, colores suaves y uso sin conexión.
Implementación
Exportación a Excel e importación inteligente: mapeo flexible de columnas, validación y vista previa antes de confirmar si se crea o se actualiza cada registro.

SmartGrow

Proyecto personal de IoT: hardware, API y dashboard para un cultivo indoor.

  • ESP32
  • Arduino
  • React
  • Fastify
  • TimescaleDB

Ver sitio de SmartGrow Código de SmartGrow

Problema
Controlar temperatura y humedad de un cultivo indoor sin tener que estar presente.
Resultado
Landing publicada y dashboard MVP funcional.
Cómo lo hice enfoque e implementación
Enfoque
Llevar el proyecto completo de punta a punta: sensores, actuadores, almacenamiento de series de tiempo y una interfaz para leerlos.
Implementación
ESP32/Arduino con sensores DHT22 y módulos de relé, API en Fastify, TimescaleDB para series de tiempo y dashboard en React con controles, analítica, terminal y documentación de la API.
